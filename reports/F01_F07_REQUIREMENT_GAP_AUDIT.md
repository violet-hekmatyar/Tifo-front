## 首页结论

1. **F01-F07 尚未覆盖原始需求第一版的全部核心闭环。** 已经形成可运行的基础产品：认证/首次设置 -> 首页 CONTENT/MATCH Feed -> 内容详情/帖子发布/互动 -> 基础足球数据详情 -> 用户中心/关注。主要缺口是 ARTICLE 真图文分段、我的点赞、球队关注上限规则，以及大量足球榜单/阵容/统计/评分和消息能力。
2. 以本次 80 条需求矩阵为分母：
   - 前端页面/入口完成度：**64%（51/80 有实际页面、交互或明确能力页）**；其中能力缺口页不算业务完成。
   - 前端业务闭环完成度：**45%（36/80 达到 A 完整闭环）**。
   - 后端真实接口支持度：**56%（45/80 有当前 Controller-Service-查询闭环）**。
   - 原始需求加权覆盖度：**50%**（A=1、B=0.5，其余=0）。
3. **球员榜不能实现**：需要后端新增统计模型、榜单接口及真实赛事数据源。
4. **球队榜不能实现**：同样需要后端统计模型、接口及数据源。
5. **联赛积分榜不能实现**：API 文档有规划路径，但当前 Java 无 Controller/Service/表；需要新增 standings 能力。
6. **球队完整球员列表不能直接由前端补齐**：底层 `team_player` 存在，但没有 roster 查询闭环；后端必须先加接口。
7. **球员赛季统计和生涯不能实现**：需要新表、聚合接口和外部赛事数据源。
8. **比赛阵容、排名、详细统计不能实现**：前端只有正式空状态，后端没有真实端点或数据模型。
9. **球员评分不能实现**：没有评分写入/聚合/查询闭环；comment 表中的孤立字段不等于评分系统。
10. **互动消息和私信不能实现**：通知、未读、会话、消息、聊天均无后端表和接口；完整私信建议第一版延期。

状态统计：A 36、B 8、C 1、D 7、E 20、F 7、G 1。P0 为 **3 个工作包**，P1 为 **8 个工作包**；需求冲突 **1 个**。

## 第一版阻塞项

按当前前端 P0 范围与原始需求共同判断，建议只保留三个 P0 工作包：ARTICLE 真图文分段读取闭环、我的点赞列表、球队最多五支规则对齐。足球深度榜单很重要，但现有范围文档将其放在 P1，且依赖外部赛事数据，不宜伪装成“前端立刻可修”的 P0。

## 非阻塞缺口

- 可直接由前端补：球队最热资讯（复用 Feed teamId）、关系状态文案、关注/取消确认交互。
- 前后端共同补：文章发布/内容关系选择、赛季列表、通知。
- 必须先补后端/数据源：积分榜、球员榜、球队榜、阵容、统计、生涯、评分。

## 选做/延期项

转会卡、讨论卡、淘汰赛爽感交互、视频集锦、裁判评分、全局搜索深化、第三方登录、完整私信 IM。视频/转会/赛事深度数据还需版权、平台条款或采购评估。

## 需求与实现冲突

仅确认 **1 个**：PDF 第 16 页要求每个用户最多关注五支球队；后端 README 与 `FollowService` 明确不设上限，且 `40902` 只是未启用预留码。不能只在 Flutter 限制；必须由产品决定最终规则，再由后端作最终判定。

## 后端缺少的功能

完整清单与建议字段见后端能力矩阵和路线图。按领域归纳：

1. 内容：ARTICLE blocks 持久化与发布/编辑；实体搜索/关联选择校验。
2. 用户：我的点赞分页；若保留上限则球队关注事务校验。
3. 足球赛事：赛季列表、standing、杯赛 stage/tie、球员/球队赛事统计与 ranks。
4. 球队/球员：roster、国家队关系、荣誉、赛季统计、appearance、生涯聚合。
5. 比赛：lineup、match/player stats、rating/vote/aggregate、裁判模型。
6. 消息：notification、未读/已读、目标跳转；长期再加 conversation/message/IM。
7. 数据基础设施：正式赛事数据导入、来源/时间戳/时区/授权元数据和更新任务。

## 建议路线

1. **F09A 原始核心闭环补齐**：三个 P0 + 可直接前端补的关系文案/确认和球队资讯。
2. **F09B 足球赛季、积分榜与榜单后端能力**：先签数据源与口径，再做表/导入/API。
3. **F09C 球队/球员详情增强**：roster、国家队、荣誉、统计、生涯。
4. **F09D 比赛详情增强与评分**：阵容、统计、排名，再单独做用户评分和风控。
5. **F09E 消息通知**：通知与未读闭环；不捆绑完整私信。
6. **F09G 首页扩展卡片**：仅消费前述已存在的榜单/评分能力。
7. 私信 IM、视频、转会中心等进入长期阶段。
