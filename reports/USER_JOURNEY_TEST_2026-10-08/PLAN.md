## 1. 通过标准

- 22 条走下来**不出现阻断**，每个功能正常用户点得到、看得到、用得成。
- 每一步都有**明确的视觉反馈**（加载 / 成功 / 跳转），不出现白屏、空屏、点了没反应。

## 3. 修复策略

**本轮做（小修：局部、不碰契约与架构）**：文案错别字 · 间距/对齐/颜色取值不统一 · 缺失或错位的 loading/empty 状态 · 图片占位与失败降级 · 返回后状态保留（页面级） · 溢出与局部布局适配 · 图标/默认值/预填/格式

## 5. 本轮不做（后续按需补测）

| 类别 | 举例 |
|---|---|
| 账号相关异常路径 | 注销账号、重复用户名/手机号、注销后登录 |
| 输入边界与校验 | 用户名长度/特殊符号、密码长度、两次密码不一致、手机号超长 |
| 网络异常 | 断网提交、断网进页面、恢复后重试、慢网 |
| 误操作与并发 | 快速连点提交、连续切 Tab、快速滚到底、未保存内容返回 |
| 会话与权限 | Token 失效（401）、隐私受限（40301）、无权访问他人收藏/评论 |
| 无障碍与适配 | 系统字体 140%、TalkBack、无效图片 URL 占位 |
| 埋点归因 | EXPOSE/CLICK/DETAIL 字段一致性（无抓包手段，无法可靠验证） |
| 其他端 | iOS、Vue 管理后台、支付、推送真实到达、压测 |
