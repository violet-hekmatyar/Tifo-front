# VR10-R1 设置页视觉几何与证据收口计划

状态：**R1 主要返修有效，但 Plan 复验发现设置主页右箭头与分隔线几何仍不合格；转入 VR10-R2**  
前置：VR10 业务、脱敏契约和交互测试有效，但 Plan 复验发现 5 类可见偏差  
目标：只修复设置/账号安全两页的可见几何与图标，并使用同一最终 APK 完成证据，不扩大业务范围。

## 1. 允许范围

允许修改：

- `apps/mobile/lib/features/user_center/presentation/pages/settings_pages.dart`
- `apps/mobile/test/features/user_center/f19_settings_acceptance_test.dart`
- 必要时新增一个 VR10 专用视觉几何测试文件
- VR10 执行记录与 `VR10_SETTINGS_ACCOUNT_SECURITY_VISUAL_PARITY_EVIDENCE/`

禁止修改：

- 后端、`phoneMasked` 契约、数据库和认证流程；
- 设置页文案和当前“暂未开放”业务边界；
- 登录、消息、个人主页、内容、足球页及 VR11 范围；
- 为通过截图而放宽几何阈值、使用 fixture APK 或修改原型图。

## 2. 顺序执行模块

### R1-M0：先补失败几何断言

在改生产代码前补充可复现当前偏差的测试：

1. 375×812dp 下设置分组 x≈10dp、宽≈355dp、高≈200dp。
2. 退出块 x≈24dp、宽≈327dp、高≈54dp；与设置组垂直间隔约 24dp，top 约 330dp。
3. 两个分组都存在 `行数-1` 条分隔线；线条约 0.5～1dp，左右按原型内缩。
4. 四个图标分别为盾牌、齿轮、通知铃、翻译语义，不得使用账号头像或调节滑杆代替。
5. 账号安全标签左侧约 25dp；手机号值与箭头位于右侧，长脱敏值不会挤压标签或越界。
6. 标题字号约 19～20sp，中心位置与两张原型一致。

完成门槛：新增断言在当前代码上明确失败，且失败原因对应上述偏差。

### R1-M1：设置主页几何修复

1. 图标改为线性盾牌、齿轮、通知铃、翻译；统一深色、约 22～24dp。
2. 在四行之间加入 3 条浅灰分隔线。分隔线不得增加分组总高度；每行可使用底边或在固定 200dp 内均分。
3. 标题调整到原型约 19～20sp，返回箭头保持细线、无底色且可点击。
4. 设置分组保持左右 10dp、四行各约 50dp。
5. 退出块单独增加水平内缩，使页面 x≈24dp、宽≈327dp；分组到底部间距改为约 24dp，使 top≈330dp。
6. 保持大面积浅灰留白，不增加说明文字、副标题或额外卡片。

完成门槛：R1-M0 的设置页几何测试通过，退出确认与 busy/失败行为不变。

### R1-M2：账号安全行布局修复

1. 账号安全行不得保留空图标占位；标签从页面 x≈25dp 起。
2. 使用专用行布局：左侧标签，`Spacer/Expanded` 吸收剩余空间，右侧可选值，再接箭头。
3. 手机号脱敏值使用浅灰色、单行省略，并贴近右侧箭头；“未绑定”使用相同位置。
4. 3 行之间加入 2 条与原型一致的内缩分隔线，分组总高仍约 150dp。
5. 保持标题“设置”、三行文案和所有“暂未开放”交互不变。

完成门槛：标签 x、值/箭头右侧位置、三行高度和分隔线数量均通过几何测试；360dp、140% 字体无 overflow。

### R1-M3：定向回归

1. 运行 `f19_settings_acceptance_test.dart` 和新增 VR10 几何测试，记录准确通过项数。
2. 回归登录重定向、退出取消/成功/失败/busy、`AuthUser.phoneMasked` 解析，不重跑无关大套件。
3. 运行 `flutter analyze`、前后端 `git diff --check`。
4. 本轮不再修改后端；可复用已通过的 6 项 `AuthServiceTests` 结果，若契约文件意外发生变化则必须重跑。

完成门槛：所有定向检查通过，工作树没有 R1 范围外新增修改。

### R1-M4：普通 Terminal 构建与视觉证据

1. 由于 Codex 进程存在 Java loopback 故障，在普通 Windows Terminal 从当前最终源码构建 APK；不得使用旧 APK。记录完整 SHA-256。
2. 安装同一个 APK，先验证真实登录与 `/api/auth/me` 的脱敏手机号，再采集：
   - `01_settings.png`
   - `02_account_security.png`
   - `03_unavailable_feedback.png`
   - `04_logout_confirm.png`
   - `05_360dp_settings.png`
   - `06_360dp_account_security.png`
   - `07_140_percent_settings.png`
   - `08_140_percent_account_security.png`
3. 用原始原型和本次原始截图制作 2 张直接双栏对照，不得嵌套旧 comparison。
4. `VISUAL_COMPARISON.md` 记录关键目标/实际/误差：标题、分组、行高、分隔线、图标、退出块、账号标签和值/箭头位置。
5. 证据不得包含完整手机号、Token 或密码；手机号只允许显示脱敏值。
6. 结束后恢复设备为 1080×2400、density 420、font scale 1.0。

完成门槛：8 张正式图、2 张直接对照、同 APK 哈希、真实脱敏数据和设备恢复记录齐全。
