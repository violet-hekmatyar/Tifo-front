# F08 人工 UI 复验清单

- [ ] 错误密码显示可理解错误，不输出堆栈、密码或 Token。
- [ ] 管理员登录后进入 Dashboard，刷新页面和 `/admin/users` 子路由可恢复会话。
- [ ] 普通 USER 登录显示无后台权限，直接访问 `/admin/**` 进入 403。
- [ ] 无 Token 访问后台回登录；过期 Token 清理；断网保留 Token 并可重试；403 不清 Token。
- [ ] 登录页支持密码显隐、Enter、防重复和表单校验，无注册/验证码/第三方入口。
- [ ] 侧栏可折叠、菜单高亮正确；顶部显示真实管理员昵称/用户名和退出。
- [ ] Dashboard 无假用户数、内容数、比赛数或图表；四个模块占位不展示假数据。
- [ ] 404 页面正确；站外 redirect 参数不能跳出本站。
- [ ] 桌面常用宽度与窄窗口无关键操作遮挡，浏览器控制台无 Token/密码。
