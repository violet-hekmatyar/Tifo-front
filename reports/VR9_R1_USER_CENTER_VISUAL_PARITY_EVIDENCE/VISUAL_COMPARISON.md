## 数据与接口核对

- R1 Seed 连续执行一次，Validator 连续执行两次；本人内容 8 条、公开用户内容 9 条、媒体 12 条、球队关注 3 个、球员关注 3 个。
- VR9-M1 保留的 20 条用户关系未被 R1 Seed 改写；Validator 的非 DEMO 泄漏为 0。
- 已有登录态只读 API 记录确认 `auth/me`、本人摘要/看台/内容、公开资料/内容、关注和粉丝接口返回 HTTP 200、`code=0`；凭据和 token 未写入报告。
- 图片兜底遵循“网络图片优先、本地图片兜底、最后才是首字母”的顺序；R1 正式正常态截图中的用户头像均以图片呈现。

## 量测口径

正式截图以应用内容区为比较坐标，不把系统状态栏和底部手势区计入页面锚点。R1 重点检查：

- 资料头：三统计、深色蒙层、Tab 顶边与设置入口；
- 内容流：首卡位置、双列连续性、封面可见性和首屏卡片数量；
- 关系页：Tab 底边、搜索框高度/位置、首行及连续行节奏；
- 适配：360dp 与 140% 字体下无 overflow、按钮和关系状态仍可识别。

本记录提供给 Plan 模型做逐图复验，不自行宣布 VR9 或 VR9-R1 通过。
