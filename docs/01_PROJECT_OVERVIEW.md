> 版本：v0.1  
> 当前阶段：F00  
> 文档定位：说明产品、客户端组成、第一版目标和职责边界。  
> 不负责：完整依赖、目录树、任务表或接口路径表。

## 项目定位

南看台是以足球内容、赛事数据和社区互动为核心的产品。前端由两个独立客户端组成：

- Flutter 原生移动 App：面向普通用户，承载内容浏览、足球数据、互动、关注和个人中心；
- Vue 3 + TypeScript 管理后台：仅供内部管理员发布内容与维护用户和足球基础数据。

当前不建设面向普通用户的 H5、PWA、小程序或 React Web。

## 仓库关系

- 前端根目录：`D:\Football-APP-Front`
- 后端根目录：`D:\Football-APP`

二者是独立项目和 Git 仓库。前端可读取并同步后端文档快照，但不得修改后端文件，也不得依赖后端 Java 内部实现。

## 第一版核心闭环

用户完成注册登录和首次偏好选择后，浏览混合卡片流，进入内容与足球数据详情，完成评论、回复、点赞、收藏、关注和发布，再从“我的”查看个人数据；管理员通过内部后台维护用户、内容和足球基础数据。

## 职责边界

前端负责展示、交互、客户端状态、路由守卫、请求编排和可恢复错误提示；后端负责身份与权限最终判定、业务规则、数据持久化、接口契约和文件安全。前端校验用于体验优化，不能替代后端校验。

## 第一版不做

不做完整私信 IM、WebSocket 实时比分、完整约球聊天室、广告与支付、复杂动态权限平台、第三方赛事数据自动接入、微前端或 SSR。
