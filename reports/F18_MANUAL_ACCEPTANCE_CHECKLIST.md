# F18 Android 人工验收清单

## 验收准备

| 项目 | 要求 |
|---|---|
| 设备 | Android 模拟器 Pixel 8，先使用默认字体，再切换到 140% 字体 |
| 后端 | 启动当前 Backend V1 Spring Boot，App 的 `API_BASE_URL` 指向模拟器可访问地址 |
| 数据 | 使用独立验收账号；准备至少一条 ARTICLE、一场有阵容/统计/评分的比赛，以及可搜索的球队和球员 |
| 通用观察 | 每页检查返回、连续快速点击、上下滚动、加载中、空数据、断网重试和图片加载失败 |

记录方式：通过填 `✓`，失败填 `✗` 并记录页面、操作、截图和后端 traceId。

## 1. 登录与首次设置

| 状态 | 点击路径与操作 | 预期结果 |
|---|---|---|
| ☐ | 启动 App → 注册 → 输入用户名、手机号、密码 | 校验提示清楚；注册成功后可登录；密码不明文回显 |
| ☐ | 登录 → 首次设置 → 选择主队、关注球队和球员 → 前进/返回 | 选择状态保留；无“最多 5 支球队”的旧限制；提交后进入首页 |
| ☐ | 登录页打开键盘并切换 140% 字体 | 输入框和登录按钮可滚动到，不被键盘遮挡，无溢出黄条 |
| ☐ | 使用错误密码、断网后登录、恢复网络后重试 | 错误信息明确；按钮恢复可点击；不会进入错误登录态 |

## 2. 首页六类 Feed 与全局搜索

| 状态 | 点击路径与操作 | 预期结果 |
|---|---|---|
| ☐ | 首页 → 推荐，连续下滑 | CONTENT、MATCH、HOT_COMMENT、DISCUSSION、RANKING、PLAYER_RATING 按真实数据展示；无 Demo 文案 |
| ☐ | 首页 → 资讯 / 关注 / 球队筛选 → 下拉刷新 → 加载更多 | 筛选正确；分页不重复；加载、到底、失败重试状态明确 |
| ☐ | 点击六类卡片及卡片中的球队、球员 | 进入对应现有详情；返回后首页筛选和滚动位置保留 |
| ☐ | 首页 → 搜索，空关键词点击搜索 | 不发送无意义请求，保持输入提示状态 |
| ☐ | 搜索“曼” → 全部 / 球队 / 球员 / 比赛 / 内容 | 四类真实结果可查；切换分类时旧结果正确重置 |

## 9. 推荐行为

| 状态 | 点击路径与操作 | 预期结果 |
|---|---|---|
| ☐ | 首页停留但不滚到屏幕外卡片，再滚动使卡片进入视口 | 只有真正进入可见区域的卡片产生 EXPOSE；接口返回本身不算曝光 |
| ☐ | 点击 Feed 卡片 → 进入详情 | CLICK、DETAIL 使用同一 requestId/impressionId/position/algorithm/model/experiment 归因 |
| ☐ | 从推荐内容详情完成点赞、收藏、评论 | 业务接口成功后才产生 LIKE/FAVORITE/COMMENT；取消动作或失败不产生成功行为 |
| ☐ | 上报接口断网后继续浏览和互动 | 导航和业务操作不被阻塞；恢复后仅有限重试，无持续弹错 |
| ☐ | 快速退出账号并登录另一账号 | 旧账号待发送事件不以新账号身份上报 |

## 10. 通用异常、返回与可访问性

| 状态 | 点击路径与操作 | 预期结果 |
|---|---|---|
| ☐ | 在首页、搜索、榜单、详情和用户列表分别模拟断网 | 页面保留可理解错误信息和重试入口；恢复网络后可继续 |
| ☐ | Token 失效后触发受保护请求 | 40101/40102 清理本地 Token 并回登录；不会循环请求 |
| ☐ | 每个二级/三级页面使用 App 返回键和系统返回手势 | 返回层级一致；筛选、Tab、关键词、分页和滚动状态按需求保留 |
| ☐ | 设置系统字体 140%，完整走一遍核心路径 | 无 RenderFlex overflow；按钮文字不截断；列表和弹窗可滚动 |
| ☐ | 使用无效或断开的图片 URL | 球队、球员、用户和内容图片均显示稳定占位，不抛异常 |
| ☐ | 快速点击提交按钮、连续切换 Tab、快速滚到底部 | 无重复请求、重复发布、重复评分、状态串页或崩溃 |
