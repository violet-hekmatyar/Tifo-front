# F07 人工 UI 复验清单

> 自动测试与 APK 构建不能替代本清单。建议使用 Pixel 8 / Android API 36，并额外设置 140% 字体。

- [ ] 我的 Tab 显示真实头像、昵称、用户名、简介、主队和统计，无手机号、假数字或 overflow。
- [ ] 我的发布可刷新、分页、到底、错误重试；点击进入真实详情，返回仍保留原 Tab 与列表位置。
- [ ] 我的收藏与评论显示真实记录；我的点赞明确说明接口暂不可用。
- [ ] Feed 卡和内容详情作者均可进入公开用户主页；非法/不存在用户停留在错误或空状态，不回首页。
- [ ] 其他用户关注按钮即时变化、连续点击不重复请求、失败回滚；自己的主页没有关注按钮。
- [ ] 关注的人、粉丝列表可分页并进入用户主页。
- [ ] 关注球队/球员可进入 F06 详情，取消关注成功刷新，失败时保留状态。
- [ ] 消息 Tab 正式说明后端能力暂不可用，无假消息、假红点或假未读数。
- [ ] Android 返回键逐层返回；底部四 Tab 状态保持；键盘/系统字号/长文本无黄黑 overflow。
- [ ] 断网下首屏与追加错误均可理解并可重试；401 返回登录，403 不清会话。
