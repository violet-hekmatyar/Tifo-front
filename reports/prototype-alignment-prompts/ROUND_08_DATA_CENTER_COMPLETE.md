- 保留 `CURRENT_STANDING` 的既有契约语义：它表示“当前排名”，不得解释成预测、历史名次或客户端计算结果。

## 5. Gate 1：数据中心公共骨架、导航与筛选

按原型对齐页面的主要信息层级，但复用已完成的绿色 Design Token 和悬浮底部导航：

- 页面顶部形成清晰的数据中心头部，不回退到旧紫色视觉；
- 四个主 Tab 使用紧凑、统一的绿色选中态，可横向滚动，切换后准确显示对应内容；
- 赛程来源与联赛选择可横向滚动，长联赛名不挤压相邻项；
- 榜单的赛事、赛季、阶段、指标筛选改成窄屏可靠的响应式布局。可以采用两列、自适应换行或项目一致的选择弹层，但标签、当前值和可点击范围必须完整；
- 360px 与 412px 宽、DPR 1、1.4 倍字体下，筛选区不得出现黄色/红色 overflow 条纹、文本互相覆盖、裁切下拉箭头或横向越界；
- loading 期间只禁用会造成冲突的操作，不让筛选值莫名消失；
- 切换赛事后正确重载赛季和阶段；切换赛季后正确重载阶段；切换阶段/指标后清理旧榜单并发起唯一的新请求；快速连续切换时旧响应不得覆盖最后选择；
- 从球队、球员或比赛详情返回后，数据页保留当前主 Tab、来源/筛选和已加载列表，不做无意义的全量重置。

为四个主 Tab、来源项和所有筛选控件添加稳定、语义清晰的 Key，供行为测试定位。

## 6. Gate 2：赛程与重要比赛

- 赛程按本地日期分组，日期标题清晰；今天/明天等相对标签只在能够由真实时间可靠判断时显示；
- 使用现有 `match_display_sort` 规则稳定排序，不因分页到达顺序打乱已展示分组；
- 比赛卡片对齐原型的信息层级：赛事/阶段、开赛时间或比分、状态、主客队名称与队徽；存在真实事件摘要时才显示摘要，无摘要不留固定空白；
- 未开始、进行中、已结束、延期/取消及 unknown 状态安全降级；缺队徽、缺阶段、长队名和缺比分不崩溃；
- 重要、关注、指定联赛来源切换正确。未登录或无关注数据应呈现真实错误/空态，不伪造比赛；
- 点击比赛进入现有比赛详情；如当前卡片已有球队点击能力则保留，禁止新增无契约操作；
- 支持首屏 loading、empty、failure/retry、下拉刷新、分页 loading、分页失败保留数据并重试同一页、去重和“已经到底了”；
- 页面底部内容必须为悬浮导航和 SafeArea 留足空间。

## 7. Gate 3：积分榜

- 展示排名、球队、场次、胜/平/负、进失球或净胜球、积分等当前模型真实提供的字段；字段缺失显示合理占位，不自行推导；
- 表头与数据列严格对齐，球队名称获得弹性空间；窄屏可采用合理的紧凑列或受控横向滚动，但不能让数字错列、覆盖或跑出屏幕；
- 点击有效球队进入现有球队详情；缺失/无效 ID 时不可误跳；
- 排名分区色只在后端/模型明确提供可解释语义时使用。不能仅按截图中的名次范围伪造欧战、升级或降级区；
- `CURRENT_STANDING` 只显示为“当前排名”语义，不进行客户端推测；
- 空榜、未知阶段、空组别、长球队名、缺队徽和异常数值安全降级；
- 联赛和杯赛均使用现有 standings 能力。杯赛若只有阶段/分组积分，则展示阶段/分组榜或列表；不得生成截图中的完整淘汰树。

## 8. Gate 4：球员榜与球队榜

- 球员榜按原型形成清楚的“指标选择 + 排名列表”：名次、头像、球员名、球队、出场数和指标值只展示真实字段；
- 球队榜展示名次、队徽、球队名、场次和指标值；
- 指标入口在窄屏和大字体下可用。可以使用横向指标栏或选择弹层，不要求机械复制原型左侧超长栏，但必须让所有现有 `PlayerRankType` / `TeamRankType` 可选择、选中态明确；
- 选择不同指标后重置旧页，从第 1 页加载；快速切换防旧响应覆盖；
- 分页按实体 ID 去重，busy 时不重复请求，append 失败保留记录并重试同页，到底状态明确；
- 点击有效球员/球队进入现有详情；unknown 类型、空 ID 或缺失字段不得误跳；
- 长球员名、长球队名、空头像/队徽、空出场数、空显示值和 1.4 倍字体下不溢出。

## 9. Gate 5：统一状态、无障碍与视觉收口

- 四个主 Tab 均有可观察的 loading、empty、failure、retry 和 ready 状态；分页列表另有 append loading/failure/end；
- 首屏失败可重试，append 失败不可替换成整页错误；刷新失败保留旧内容并给出反馈；
- 所有可点击控件具有足够触控区域，选中态不只依赖颜色；
- 页面背景、卡片圆角、边框、阴影、间距、绿色强调色与 Round 01–04 已通过的设计体系一致；
- 不出现生产 mock、placeholder 文案、`TODO` 调试提示、RenderFlex overflow 或 debug 条纹；
- 不破坏主 Shell 四 Tab、未读 Badge、底部 SafeArea，也不破坏球队/球员/比赛既有路由。
