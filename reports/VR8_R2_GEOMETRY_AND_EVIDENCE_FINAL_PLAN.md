## 2. 顺序执行模块

### R2-A：修正原型测量坐标系

1. 保留原型 375×812dp（750×1624@2x）和目标宽度缩放系数 `360/375=0.96`。
2. 尺寸继续按原型像素 `/2×0.96` 换算；纵向位置不得再直接比较全屏绝对 Y：
   - 搜索输入框顶部相对 AppBar/内容区顶部；
   - Onboarding 头部高度从状态栏内容起点到白面板顶边；
   - 结果标题、首卡相对白面板顶边；
   - 底部操作区相对底部安全区。
3. 若确需绝对坐标，测试夹具必须显式注入与测量表一致的 `viewPadding`，并在断言中列明；不得把 iOS 状态栏高度当成页面组件高度。
4. 将正确目标、锚点、实际值和误差写入执行记录。所有核心阈值保持 ±8%，不得根据当前实现放宽。

完成门槛：主队头部和首卡相对位置先被证明通过或失败；不得因旧绝对坐标结果修改它们。

### R2-B：搜索空态尺寸小修

1. 非 selectionMode 搜索框视觉高度从 `48dp` 收敛至原型目标约 `39.36dp`，建议取 `40dp`；同步调整内部图标、contentPadding 和圆角，避免文字裁切。
2. 空态插画从 `64dp` 收敛至目标约 `57.6dp`，建议取 `58dp`；按原型同步文字字号和插画/文字间距。
3. 输入框纵向位置只按 R2-A 的相对锚点调整；若正确测量已在 8% 内，不得额外下移页面。
4. 保持浅灰填充、无描边、无右箭头、真实 empty/failure 分离、筛选隐藏和 selectionMode 行为不变。

完成门槛：输入框高度、插画尺寸和空态锚点在正确坐标系中均处于 ±8%。

### R2-C：三步选择卡密度收口

1. 为 Onboarding 卡片提供稳定的“视觉卡体”Key，测试不得再把外边距计入卡片高度。
2. 将卡体视觉高度收敛到原型 `60.96dp` 的 ±8% 范围；可使用局部紧凑 ListTile 参数或专用 Row，但不得改变 `AppSelectionCard` 其他调用方默认布局。
3. 将相邻卡体之间的空白/分隔线节奏收敛到原型约 `38.88dp` 的 ±8%，保留原型细分隔线；末项与操作区按原型处理，不制造多余分隔。
4. 保持 34dp 左侧真实媒体、16/12dp 主副文字、红/灰爱心、长英文省略和点击区域可用。
5. 以正确相对坐标复核头部、白面板、结果标题和首卡位置；已在容差内的项目不得修改。
6. 主队、球队、球员三页使用同一密度规则；标准设备首屏信息数量和留白应接近各自原型。

完成门槛：视觉卡体和卡间节奏分别满足 ±8%，三页无 overflow，选择交互不回归。

### R2-D：状态保持与回归测试

1. 修正 E1 两个几何测试的坐标基准，保留真实失败尺寸断言；不得删除严格测试恢复绿色。
2. 完成“球队页输入查询并滚动/选择 → 球员页 → 返回球队页”，直接断言球队查询词、选择集合和 ScrollPosition 保持。
3. 运行 VR8 冻结测试及本轮测试，总数不得低于 68 项；另运行 `flutter analyze`、VR7 两个共享回归和两仓 `git diff --check`。
4. 不执行任何数据库脚本或写入型 API。

完成门槛：正确坐标测试、尺寸测试、状态保持和响应式测试全部通过。

### R2-E：最终 APK、真实 API 与逐图证据

1. 从最终源码构建并安装一个新 APK，记录完整 SHA-256。
2. 使用已有 onboarding 已完成账号登录；不得新建账号或提交 preferences。只读验证 `options`、`auth/me` 为 `HTTP 200 + code=0`。
3. 正常进入搜索页，以唯一关键词获得真实空结果并采集标准截图；同时重采主队、球队、球员三页。不得使用 fake、旧 APK 或后处理画面。
4. 生成四张等比例 comparison：搜索空态、主队、球队、球员。原型与实机先归一到相同应用内容宽高，保持宽高比，不得只贴到不同尺寸画布。
5. 另采 360dp、140% 字体和球队状态往返保持证据；所有正式图来自同一 APK，结束后恢复 1080×2400、density 420、font scale 1.0。
6. `VISUAL_COMPARISON.md` 记录正确锚点下的目标、实际和误差；任何核心项超过 8% 均不得宣布完成。

完成门槛：四张标准图、四张 comparison、响应式证据、登录态只读 API、≥68 项测试及最终 APK 全部闭合。

## 3. 最终关闭条件

以下任一项不满足，VR8 仍不得关闭：

- 继续用含状态栏的原型绝对 Y 对比无安全区 Widget 坐标；
- 搜索框、插画、视觉卡体或卡间节奏超出 ±8%；
- 为通过测试而加高已合格头部、整体下移列表或放宽断言；
- `AppSelectionCard` 默认调用方被改变；
- 缺搜索真实实机图、任一 comparison、登录态只读回读或同 APK 证明；
- 修改后端、数据库、SQL、API 或非 VR8 页面。
