## 1. 任务

修复最终集成 APK 中已经确认的首页、数据、我的和消息四个根模块回归，使正常数据、媒体、导航状态和首屏结构重新符合原型；使用一个新 APK 完成统一验收。

## 2. 范围

允许修改：

- Flutter 主 Shell、首页 Feed 卡片布局、数据首页、本人主页媒体展示、消息首页和互动通知页；
- 与上述页面直接相关的定向 Widget/路由测试和媒体组件；
- 现有 DEMO 球队图片、关注关系和 VR11 通知数据；确需写库时新增 VR14 专用 Seed/Validator/Rollback/Manifest；
- 不改变现有 API 契约的后端媒体访问修复。

明确不做：

- 手机验证码、一键手机号登录、微信登录；
- 私信、聊天会话、IM、WebSocket、Push；
- 完整杯赛淘汰树；
- 球队详情、球员详情、比赛详情、内容详情、发布、搜索、设置和登录页面的重新设计；
- 全仓重构、依赖升级、Feed 排序算法或分页上限修改。

## 3. 强制规则

1. 当前安装 APK 基线固定为 `25857D58334BA9C356A3C84A9A145F9474C9A630B6B85A37174B89B02D336771`，旧阶段截图只能用于差异定位，不能作为 VR14 通过证据。

3. 球员头像与内容封面允许合理复用；不同球队不得在正常状态下用同一队徽冒充不同身份。
4. 图片必须返回 `HTTP 200 + image/*` 且能被 Flutter 解码；401/JSON/HTML 只能触发异常降级，不能作为正式截图状态。
