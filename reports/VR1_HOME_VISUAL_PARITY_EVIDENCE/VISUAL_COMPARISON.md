## 几何、颜色与密度记录

- 顶部搜索与发布高度约 48dp，搜索使用浅灰填充且无高对比边框，发布使用品牌绿。
- 首页内容列使用 10dp 左右边距、8dp 列间/卡间距；卡片首页组件内使用约 10dp 圆角。
- 内容卡封面使用自然裁切；正常 PNG 媒体在首屏与资讯证据中可见，图片失败仍保留中性足球占位。
- 卡内层级为封面 > 标题 > 摘要/热评 > 作者与互动；专用卡压缩内边距后进入半宽列。
- 底栏外层仍保留原型白色胶囊与阴影，Material NavigationBar 的默认浅绿色选中指示块已关闭。

## 已知验收关注点

- 当前关注球队接口和 Feed 媒体 API 均返回成功；当前账号的部分关注球队图像仍由既有 `AppTeamLogo` 降级为首字母显示，原因是该账号返回的球队图片资源不是 Flutter 当前可直接解码的 PNG。未新增接口、未修改后端或数据库，留给 Plan 模型判断是否需要单独的媒体资源补修。
- 资讯数据中部分历史演示记录自身没有封面，因此按现有契约展示中性占位；本阶段没有为截图硬编码业务图片。
