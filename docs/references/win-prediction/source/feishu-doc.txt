## 5.1 洞察分怎么讲给用户
第一版不用在界面上展示复杂公式。告诉用户：猜对方向会加分；概率给得越准，分数越高；明明只有五五开却写 95%，猜错会掉更多分。
一场比赛显示 0 到 100 分。用户完成多场比赛后，再展示长期校准能力和准确率。看台豆的输赢和洞察分分开记录，避免把运气当成判断力。

## 5.2 排行榜
- • 洞察榜：看谁长期预测得准。
- • 看台榜：看谁在用豆挑战中表现好。
- • 好友联赛优先展示熟人排名，提高参与和讨论意愿。

## 5.3洞察分和看台豆的计算
概率判断计算洞察分，洞察分决定挑战成功时的看台豆收益；方向没猜中则固定亏损挑战豆。
概率判断计算洞察分，洞察分决定挑战成功时的看台豆收益；方向没猜中则固定亏损挑战豆。

### 一、先计算洞察分
用户给三个结果分配概率：
- • 巴萨胜 p₁
- • 平局 p₂
- • 曼城胜 p₃
比赛结束后，实际结果记为：
- • 巴萨胜：`y = 1, 0, 0`
- • 平局：`y = 0, 1, 0`
- • 曼城胜：`y = 0, 0, 1`
先计算 Brier Score：
```
代码块
Plain Text
复制
B = (p₁ - y₁)² + (p₂ - y₂)² + (p₃ - y₃)²
```
B 越低，说明越准。
再换算成 0 到 100 的洞察分：
```
代码块
Plain Text
复制
洞察分 S = round(100 × (1 - B / 2))
```
round 表示四舍五入。页面显示整数分，后台结算也用这个整数，避免用户看到的分数和实际奖励不一致。

### 二、举个例子
用户判断：
巴萨真的获胜
```
代码块
Plain Text
复制
B = (0.64 - 1)² + (0.22 - 0)² + (0.14 - 0)²
B = 0.1976

S = 100 × (1 - 0.1976 / 2)
S = 90.12
```
页面显示：
本场洞察分 90
实际是曼城获胜
```
代码块
Plain Text
复制
B = (0.64 - 0)² + (0.22 - 0)² + (0.14 - 1)²
B = 1.1976

S = 100 × (1 - 1.1976 / 2)
S = 40.12
```
页面显示：
本场洞察分 40
洞察分奖励的不是“敢喊”，而是“概率给得准”。高概率押错会掉分，合理分配概率则更容易拿到高分。

### 三、看台豆怎么结算
挑战时，用户先从 10 / 30 / 50 中选一个挑战豆数量 C。
挑战结果分三种：
1.
方向命中
方向命中是指：
用户概率最高的结果 = 实际结果
命中时：
```
代码块
Plain Text
复制
基础收益系数 R = min(0.8, max(0, (S - 60) / 50))
```
意思是：
- • 洞察分 60，奖励率为 0%；
- • 洞察分 80，奖励率为 40%；
- • 洞察分 90，奖励率为 60%；
- • 洞察分 100，奖励率为最高 80%。
奖励豆：

# 06 边界和待定项
这个玩法有娱乐性和输赢感，但也更接近游戏化竞猜。第一版先把边界收窄，避免用户把看台豆理解成可以赚钱的资产。

| 当前不做 | 原因 |
| 现金充值和提现 | 会形成真实资金损失和兑付问题 |
| 看台豆转赠、交易 | 一旦可流通，就可能被当作可变现资产 |
| 赔率、奖金池、抽水 | 会明显强化博彩性质 |
| 滚球挑战、连续加注 | 容易制造高频刺激和追损 |
| 现金、彩票或高价值实物奖励 | 容易与博彩或抽奖混淆 |
| 站外博彩、跟单和私域返利入口 | 与资讯产品的边界冲突 |

## 规则玩法
假设一场比赛是：
主队胜、平局、客队胜
系统显示当前球迷共识：
这不是赔率，也不是平台承诺的概率，而是所有用户的预测经过汇总后形成的“球迷意见”。
用户小明看完阵容后，可以提交自己的判断：
三项加起来是 100%。
小明不需要充值，不扣金币，也不能把这份判断卖给别人。他只是在回答：
“我认为主队有 64% 的概率赢。”
比赛开始前最多修改 3 次，开赛后判断锁定。

## 球迷共识怎么变化
系统把所有用户的概率汇总起来，动态显示：
主胜概率从 52% 降到 46%。
可能原因是：
- • 主队首发阵容轮换；
- • 核心后卫受伤；
- • 客队近期状态提升；
- • 大量球迷改变了判断。
这里借用了 Polymarket 的“概率会随新信息变化”的体验，但没有资金仓位，也没有买卖获利。

## 赛后怎么算胜负
假设小明给出了 64 / 22 / 14 的判断。

### 主队获胜
小明最高概率的方向猜中了，同时概率分配也比较合理：
方向命中
洞察分：90

### 客队获胜
小明虽然更看好主队，但实际结果完全相反：
方向未命中
洞察分：40
评分不只奖励“猜对方向”，还会检查用户是否过度自信。一个总说“90% 必赢”却经常猜错的人，长期分数会下降；一个给出合理概率、长期判断稳定的人，会获得较高排名。
