# F03 客户端 UI 审查

> 日期：2026-07-17  
> 审查范围：F03 实际 Flutter 页面与产品 PDF 第 1、5 页视觉方向  
> 说明：本报告记录 F03.1 重构前审查结论，不声称已完成人工模拟器视觉验收。

## 当前实际运行页面

F03 路由实际包含启动恢复、登录、注册、首次设置、认证完成临时页和 404。真实后端闭环已覆盖注册、登录、会话恢复、偏好 options/preferences 与退出；Vue 管理后台仍保持 F02。

## 与产品原型的主要差异

重构前登录/注册偏默认 Material 表单，品牌顶区与内容层级较弱；Onboarding 将三类选择放在同一长列表，缺少分步进度与稳定底部操作区；球队和球员失败占位只使用通用 CircleAvatar，实体一致性不足；临时完成页功能正确但品牌感较弱。

PDF 第 1 页可采纳的是蓝紫品牌区、浅背景白卡、分步选择、明确选中态和稳定底部动作；第 5 页可采纳的是轻量卡片、紧凑层级和社区感。原型中的第三方商标、球员照片、首页业务卡片和底部导航不属于 F03.1。

## 临时完成页边界

当前认证完成页只用于证明 F03 闭环，不是正式首页。它必须只展示完成状态、非敏感用户名/昵称、F04 待开发提示与退出登录，不得加入新闻、比赛、统计或底部主导航假数据。

## 数据库图片资源现状

真实球队 Logo 与球员头像 URL 可能为空或失效。本轮不修改后端、数据库、seed，不下载随机图片，也不把未经确认的俱乐部商标和球员照片写死到客户端；统一由稳定本地占位兜底。

## F03.1 视觉调整范围

- 建立 Flutter 视觉 Token 和 ThemeData 消费；
- 建立按钮、字段、区块标题、状态、实体占位和选择卡片；

- 将首次设置改为三步 presentation 流程，保留原 Controller/Repository/API；
- 增加 Widget 回归、视觉检查脚本和人工验收说明。
