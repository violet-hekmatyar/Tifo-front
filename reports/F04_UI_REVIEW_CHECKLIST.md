# F04 人工视觉验收清单

> 当前状态：待用户在 Pixel 8 模拟器上执行。勾选项是验收步骤，不代表已经通过。

## 准备

- [ ] 在仓库根运行 `ensure-local-backend-f03.ps1`，确认 `status-local-backend-f03.ps1` 的 health/db/redis 均为 UP。
- [ ] 运行 `adb devices`；复用已有 `emulator-*`，否则冷启动 `Pixel_8_API_36`。
- [ ] 在 `apps/mobile` 用 `flutter run -d <实际设备ID> --dart-define=APP_ENV=development --dart-define=API_BASE_URL=http://10.0.2.2:8080` 启动。

## 导航与会话

- [ ] 已完成 Onboarding 的用户登录后进入正式首页，不经过 F03 临时完成页。
- [ ] 首页、数据、消息、我的四个入口清晰统一。
- [ ] 切换 Tab 后首页滚动位置与页面状态合理保留；重复点击当前 Tab 回到分支根。
- [ ] 子占位页返回正常，Android 返回键不产生重定向循环。
- [ ] 我的页只展示非敏感信息，无假统计；退出后回到登录页。

## 首页与卡片

- [ ] Header 品牌、搜索和发布入口在 Pixel 8 上无拥挤或 overflow。
- [ ] 推荐、资讯、关注选中态明确，切换时 Loading/Empty/Error 不闪出旧筛选数据。
- [ ] 关注球队横向入口来自真实账户；缺 Logo 的稳定占位一致。
- [ ] 连续内容卡为双列，标题/热评最多两行，缺热评无异常空洞。
- [ ] 内容封面和作者头像加载失败时稳定回退，不导致列表跳动或崩溃。
- [ ] 比赛卡全宽；未开始/进行中/已结束清晰；无比分时不出现伪造 `0 : 0`。
- [ ] 内容、比赛、未知卡保持接口顺序；未知卡后的内容仍正常显示。
- [ ] 搜索、发布、内容详情、比赛详情明确标注后续任务，不出现假结果或假成功。

## 状态与可用性

- [ ] 下拉刷新保持当前筛选并替换首屏。
- [ ] 滚动接近底部只触发一次分页；结束、追加错误和重试状态清晰。
- [ ] 空 Feed 显示对应推荐/资讯/关注或球队文案，不显示系统错误。
- [ ] 断网/超时首屏错误可重试，已有列表在追加失败时仍保留。
- [ ] 系统文字放大到约 140% 后核心筛选、底部导航和按钮仍可操作。
- [ ] 页面没有未经授权的真实俱乐部商标资源、版权图片或生产假数据。

调试快捷键：`r` 热重载，`R` 热重启，`d` 断开但保留 App，`q` 退出当前调试。
