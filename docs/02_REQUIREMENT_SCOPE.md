# 南看台前端需求范围

> 版本：v0.1  
> 当前阶段：F00  
> 文档定位：定义前端 P0/P1/P2、暂缓范围和待确认项。  
> 不负责：技术选型、接口字段、目录结构或具体实现。

## P0：Flutter 移动端

- 启动、注册登录与会话恢复；
- 首次登录选择主队、关注球队和关注球员；
- App 主框架；
- 首页推荐、资讯、关注及球队入口；
- 至少支持 `CONTENT_CARD`、`MATCH_CARD`；
- 内容详情与帖子/文章两种渲染；
- 评论、二级回复、点赞、收藏；
- 发布帖子与图片上传；
- 数据页，球队、球员和比赛详情；
- “我的”页面及关注关系。

## P0：Vue 管理后台

- 管理员登录、后台布局和仪表盘；
- 用户列表与状态维护；
- 内容列表、状态维护、发布和编辑；
- 联赛、球队、球员、比赛基础数据维护；
- 文件上传；
- 后端已提供能力范围内的基础操作日志查看。

## P1

多类型卡片混排深化、热门评论/讨论、积分与球员/球队榜、比赛评分、球队与球员深度数据、消息提醒、内容关联和更完整的管理编辑体验。

## P2

完整约球、私信、实时比分、淘汰赛树、转会中心、复杂推荐、搜索、推送、第三方赛事数据自动接入、广告和会员支付。

## 暂缓

面向用户的 H5、PWA、小程序、微前端、SSR、React/Nuxt、完整 IM、WebSocket 实时比分、复杂动态权限平台及自动化第三方体育数据接入。

## 边界与待确认项

原型存在不代表功能自动进入 P0，P1/P2 提升优先级必须人工确认。接口可用性以当前后端实际实现和后端原始契约为准；完整视觉系统、管理端 Token 最终存储策略、消息/评分深度、iOS 发布条件和生产部署参数留待后续任务确认。
