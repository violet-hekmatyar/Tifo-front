## 模块与执行顺序

### M0：基线与映射

- 原型尺寸为 `750×1808`，按 2× 换算为 `375×904dp`。
- 固定 9 个语义：搜索无结果、网络故障、暂无关注、暂无关注球队、暂无浏览记录、暂无评论、暂无收藏、暂无数据、暂无消息。
- 记录现有 `AppStateView`、搜索专用空态及目标业务页面基线；不得扫描或替换全部空态。
- “暂无浏览记录”只作为组件变体和图谱证据，不新增不存在的浏览记录功能。

### M1：共享插画组件

- 新增 `AppStateIllustrationType` 与 `AppStateIllustration`，覆盖上述 9 种语义。
- 使用 `CustomPainter`、现有 Material 图形或代码几何绘制；主体为品牌绿，右下有深灰错位阴影，并保留原型的虚线轮廓和顶部三条提示线。
- 标准插画视觉尺寸约 `56～64dp`，组件自身提供稳定 Key、Semantics label 和可选尺寸；不加载网络或位图资源。
- 搜索、Wi-Fi、人物、盾牌、时钟、对话、星形、饼图、铃铛轮廓应能一眼区分，不能只更换同一个 Material 图标。

### M2：安全接入现有空态

- `AppStateView` 增加可选 illustration 参数；未传入时保持旧表现，禁止全局改变已通过页面。
- 最小接入：
  - 关注的人/粉丝空列表 → 暂无关注；
  - 关注球队空列表 → 暂无关注球队，关注球员 → 暂无关注；
  - 我的/用户评论空列表及评论区空态 → 暂无评论；
  - 我的/用户收藏空列表 → 暂无收藏；
  - 数据中心明确空数据 → 暂无数据；
  - 互动通知空列表 → 暂无消息。
- 搜索页已由 VR8 通过，除非能证明组件替换后几何完全不变，否则不修改其生产代码；图谱仍必须展示“搜索无结果”变体。
- 网络故障只用于明确的网络错误状态，不把业务 404、权限错误或普通空列表误画成网络故障。

### M3：原型图谱测试页

- 仅在测试支持代码中构建 `375×904dp` 图谱，不新增生产路由或入口。
- 图谱包含居中“二级页标题”、返回图标、两列五行布局；前四行各两项，第五行仅左侧“暂无消息”。
- 标签顺序必须与原型一致，插画约 `60dp`、标签约 `15sp` 灰色，列中心和行间距形成稳定几何断言。
- 生成可复现的图谱基准图；测试不得依赖网络、数据库或真实账号。

### M4：定向测试

至少覆盖：

- 9 种类型均有独立语义、前景轮廓和稳定 Key；不存在九项共用同一图形的退化实现。
- 图谱为两列五行，项目顺序、列中心、行中心、插画尺寸和标题位置符合原型量测。
- `AppStateView` 未指定插画时保持兼容；指定插画后标题、说明、重试按钮和回调不回归。
- 收藏、评论、关注、球队、数据和消息页面分别映射正确变体。
- 360dp 与 140% 字体下无 overflow，长文案最多合理换行，重试按钮可点击。
- 错误、空数据、受限状态不得被错误归类。
