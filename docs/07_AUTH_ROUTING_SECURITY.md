# 南看台前端鉴权、路由与安全

> 版本：v0.1  
> 当前阶段：F00  
> 文档定位：会话、路由守卫和前端安全边界的唯一权威文档。  
> 不负责：后端 BCrypt/JWT/Redis 内部实现或完整接口说明。

## Token 与会话

Flutter Access Token 使用 `flutter_secure_storage`，普通偏好与非敏感 onboarding 标记可使用 `shared_preferences`。管理后台 Token 的最终存储方案在 F01/F08 结合风险确认；不得放入源码、构建常量、URL 或可公开日志。

App 启动时恢复 Token，调用权威会话接口验证并读取用户状态：未登录进入登录页；`onboardingCompleted=false` 进入首次选择；已完成进入主框架。启动期间显示明确的恢复状态，避免先进入受保护页面再闪退跳转。

## 路由守卫

Flutter 守卫以认证状态与 onboarding 状态为输入，保证跳转幂等。管理后台除登录/错误页外默认需要认证，并且只允许 `ADMIN`。普通 `USER` 进入后台时展示无权限、清除错误会话状态并回到登录入口。

`40101`、`40102` 由统一网络层触发一次会话清理和重定向；多个并发失败不得产生多次弹窗或循环跳转。退出登录应停止用户请求、清除内存状态和安全存储，并替换路由栈。

## 安全边界

- 不打印完整 Token、密码、密钥或敏感响应；
- 环境变量模板只含占位值，真实密钥不进入前端仓库；
- 前端不存在数据库凭据，不尝试还原服务端 JWT 或权限逻辑；
- 文件上传前校验类型和大小以改善体验，后端仍是最终校验方；
- 隐藏按钮不是权限控制，所有权限以后端判定为准；
- 外部 URL、富文本、文件名和错误消息按使用场景转义/校验，不执行服务端返回脚本。
