> 自动测试与 APK 构建不能替代本清单。以下项目默认待用户在 Pixel 8 / Android 真机确认。

## 启动

- [ ] `ensure-local-backend-f03.ps1` 与 `status-local-backend-f03.ps1` 显示 health/db/redis 均 UP。
- [ ] `adb devices` / `flutter devices` 获取实际设备 ID。
- [ ] 在 `apps/mobile` 运行：

```powershell
flutter run -d <实际设备ID> `
  --device-timeout 120 `
  --dart-define=APP_ENV=development `
  --dart-define=API_BASE_URL=http://10.0.2.2:8080
```

## 数据页

- [ ] “数据”Tab 不再显示 F04 占位。

- [ ] 排名无接口时显示正式空能力说明，不出现假积分榜。

## 比赛

- [ ] 主客队可进入球队详情，事件球员可进入球员详情。

- [ ] Android 返回键逐级返回；无历史栈时回到数据入口。

## 路由排序修正复验

- [ ] 数据 Tab 中进行中比赛在顶部，即将开始其次，已结束最后且最近结束优先。
- [ ] 重要、关注和不同联赛均遵守同一排序，日期组跟随排序结果。
- [ ] 点击比赛卡进入真实比赛详情而不是首页。
- [ ] 点击主队/客队进入球队详情，返回仍是原比赛。
- [ ] 有真实 playerId 的事件可进入球员详情；无 playerId 不出现假入口。
- [ ] 首页 MATCH、球队赛程和内容 MATCH 关系进入同一详情。
- [ ] 滚动到底可见加载/重试/到底 Footer，末卡不被底栏遮挡。
- [ ] Android 返回键、Pixel 8 和 140% 字体无回首页异常或 overflow。

## 最终球队入口人工复验

- [ ] 首页关注球队卡右上角不再有独立小箭头或额外按钮。
- [ ] 点击真实球队卡任意位置直接进入对应球队详情，按压反馈自然。
- [ ] 点击球队前不改变 Feed 球队筛选；“全部”仍正常恢复全部 Feed。
- [ ] 返回后推荐/资讯/关注 tab、球队筛选、原 Feed 列表和滚动位置均保留。
- [ ] Pixel 8 与 140% 字体下无 overflow，语义朗读为“查看 <球队名称> 详情”。
- [ ] 页面事实仍来自后端 API，没有显示联网核验硬编码内容。
- [ ] 数据审计报告/corrections 未包含或处理视觉/媒体资源，也未自动应用到后端。
