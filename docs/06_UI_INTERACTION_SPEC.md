# 南看台 UI 与交互规范

## F06 路由与分页可观察性修正

比赛卡整卡进入比赛详情，球队区域另有 Ink/chevron 和“查看球队详情”语义；事件仅在真实 playerId 存在时提供球员入口。分页 Footer 位于末卡之后，显示“正在加载更多… / 点击重试 / 已经到底了”，追加失败保留旧数据并停止自动重试，用户点击后再恢复。详情逐层 push/pop，无历史栈才兜底数据 Tab。

## F06 数据与详情交互

数据页顶部依次提供“重要”“关注”和后端联赛横向入口，当前选择有明确描边/背景；切换来源时清空旧结果并隔离迟到请求。赛程按本地日期分组，状态同时使用文字和颜色，无比分展示时间。列表支持下拉刷新、近底分页、追加失败保留旧列表并可重试。

球队、球员和比赛详情使用品牌头部与紧凑 Tab，`IndexedStack` 保留当前 Tab。比赛总览按后端顺序展示事件，战报进入内容详情，球队/球员实体可继续跳转。不存在返回空状态，其他错误提供重试；无历史栈时返回数据主入口。无后端接口的阵容、排名和统计用正式能力空状态说明，不显示假值。

## F05 详情、评论与发布

多图横向滑动带页码；ARTICLE 按正文后媒体展示。评论排序采用后端 hot/latest，二级回复扁平展示，删除前确认。发布页提供草稿离开确认和逐图上传/失败重试，失败保留文本。

## 移动端优先

正式用户端是 Flutter 原生 App。首页采用混合卡片流：`CONTENT_CARD` 支持双列/信息流适配，比赛、榜单和评分等数据卡片优先全宽。通过 `FeedCardRenderer` 或卡片注册表按 `cardType` 分发渲染；未知类型展示轻量兼容占位并记录诊断信息，不阻断列表。

帖子详情以集中式文字与图片为主；文章详情支持图文分段。封面和正文图片使用明确宽高比、居中裁切与失败占位，多图支持横向浏览。原型仅为参考，落实前必须转成文字规则。

## F03 认证与首次设置

登录/注册表单在键盘弹起时使用可滚动布局，提供本地字段校验、密码显隐、合理焦点流、禁用/加载按钮和安全接口提示，并阻止重复提交。Onboarding 明确区分 loading、empty、error/retry、选中态和 submitting；主队单选，球队/球员多选。authenticated placeholder 只说明 F03 完成和 F04 待开发，不模拟首页数据。

F03.1 将 Onboarding 呈现为主队、球队、球员三步流程，顶部显示进度，底部操作区稳定；切换步骤不丢失选择，仅最后一步提交。完整颜色、间距、卡片和图片占位规则由 13 维护，本文件不重复 Token 表。

## 通用状态与列表

所有页面明确区分首次加载、骨架/进度、空状态、可重试错误、无网络和内容状态。下拉刷新替换首屏数据，分页追加且防止并发重复请求；切换 tab 应保留合理滚动和筛选状态。

点赞、收藏、关注等 toggle 可即时反馈，但必须防重复提交；失败时回滚并提示，最终以后端状态为准。发布、评论、保存等写操作在进行中禁用重复触发。

## 管理后台

列表页统一包含筛选、表格、分页、加载/空/错误状态。表单区分创建与编辑，字段错误就近提示；危险状态变更使用确认弹窗，成功后刷新受影响行。状态以可访问的文字和标签共同表达，不仅依赖颜色。

F00 不定义完整颜色、字体、间距和动效系统；这些在 F01/F04 结合产品确认补充。
# F04 主框架与首页补充

认证完成后显示四栏底部导航：首页、数据、消息、我的；切换分支保留状态，重复点击当前入口回到该分支根。数据与消息只显示阶段说明，我的页仅显示非敏感用户信息、后续说明和退出登录，不展示假统计。

首页由品牌 Header、可理解的搜索/发布入口、推荐/资讯/关注筛选、真实关注球队横向栏和混合 Feed 组成。内容卡双列、比赛卡全宽并保持后端顺序。首次加载、分筛选空状态和首屏错误复用 `AppStateView`；下拉刷新替换首屏，接近底部自动分页，追加错误在列表底部重试且保留已有内容。详情点击只进入带真实 ID 的后续任务占位页。

## F05 首页联动规则

首页点击发布采用 push；成功提交后详情替换发布页。详情顶部返回与 Android 返回键统一：有历史则 pop，无历史回退 `/app/home`。返回保留首页主 Tab、Feed tab、球队筛选和已有滚动控制器，并触发一次真实刷新。首页卡片固定呈现为连续全宽 MATCH 区、双列 CONTENT 区、末尾 Unknown 兼容区；奇数内容卡只占左列。

## F06 首页球队入口

关注球队横向栏不采用“整卡筛选 + 角标跳转”的双重交互。真实球队整卡是唯一点击区，按压反馈覆盖整卡并直接 push 球队详情；点击前不改变 Feed 筛选。“全部”仍清除球队筛选。teamId 非法时禁用该卡，不构造错误路由。语义标签为“查看 <球队名称> 详情”；返回保留 Feed tab、原筛选、列表与滚动位置，Pixel 8 和 140% 字体不得 overflow。
