# VR11-R2 视觉对照说明

## 纳入页面

- `comparison_01_messages.png`：左侧为 `消息.png` 原型原图，右侧为同一最终 APK 的 `01_messages.png`。
- `comparison_02_interactions.png`：左侧为 `消息-互动消息.png` 原型原图，右侧为同一最终 APK 的 `02_interactions.png`。

两张图均为直接双栏对照，未使用旧 comparison、嵌套合成、人工高亮边框或调试边界。原型原图尺寸为 `750×1624`；APK 原始截图为 `1080×2400`，右侧仅按宽度等比缩放到 750。

## R2 对照检查点

### 消息首页

- 标题约 18sp；绿色互动入口直径 44dp，R2 顶部 padding 约 2dp，标题中心到入口中心约 62dp。
- 页面只展示真实“互动消息”入口，没有虚构私信会话行。
- 全部已读稳定态不显示入口红点、底部未读角标或额外已读动作。

### 互动消息

- 为独立全屏页，标题、返回入口和列表左右边距保持原型结构；R2 顶部 padding 约 2dp，标题中心到首个头像中心约 60dp。
- 标准字号通知行约 60dp，头像和内容封面约 40dp；高字号时行高自适应避免溢出。
- 使用真实演员头像、内容获赞文案、相对时间和内容封面；无封面但资源可用时保留 40dp 占位；列表末尾不显示“没有更多消息了”。
- 目标内容可进入真实详情页；未开放私信搜索显示明确反馈。
- 360dp 与 140% 字体截图均来自同一 APK，未出现溢出标记或人工边框。

视觉是否达到原型逐图放行标准，交由 Plan 模型最终复验。
